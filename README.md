# 小步

一个界面就能完成的习惯追踪工具，面向大学生、自由职业者和希望保持节奏的人。无需安装、无需构建，打开即用。

## 一句话简介

一个界面完成习惯打卡、专注计时、便签与日程的极简追踪工具。

## 功能

- 今日：习惯打卡、完成进度环、连续天数、实时时钟
- 专注：25 / 5 / 15 分钟计时、进度条、环境音
- 快捷导航：可添加常用网址，点击在新标签打开
- 闪念便签：P1 / P2 / P3 优先级、勾选完成、删除
- 今日时间块：按时间排序的安排，支持完成与删除
- 统计：本周柱状图、总打卡、最佳连续、30 天完成率、习惯表现
- 日历：月度热力图，按天查看完成情况
- 设置：跟随系统 / 浅色 / 深色主题、习惯管理、JSON 导入导出、恢复示例、清空数据

## 运行

方式一：双击 `start.bat`，浏览器打开 http://127.0.0.1:5173/。

方式二：

```bash
python -m http.server 5173
```

然后访问 http://127.0.0.1:5173/。

也可以直接打开 `index.html`。

## 技术

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- localStorage 本地持久化，旧数据自动兼容
- CSS 变量实现深浅色主题，支持响应式与移动端安全区
- SVG 绘制进度环，Web Audio API 生成环境音
- 提供 PWA 清单，可添加到主屏幕

## 目录

```
index.html              页面骨架
styles.css              视觉与布局
app.js                  状态、渲染与交互
manifest.webmanifest    PWA 清单
icon.svg                应用图标
start.bat               本地启动脚本
docs/work-detail.md     作品详情
```

## 隐私

所有数据仅保存在本机浏览器的 localStorage 中，不上传服务器。

## 浏览器支持

Chrome / Edge / Safari 等现代浏览器。环境音需要用户点击后才会播放。
